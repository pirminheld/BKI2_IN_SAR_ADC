# SAR-ADC verstehen

`index.html` per Doppelklick öffnen. Alle Simulationen laufen offline ohne Installation. Die Quellenlinks sind ergänzend und benötigen Internet.

Vier Bereiche: Zahlenratespiel, schrittweiser SAR-ADC, lineare Sensorumrechnung, Übungen und Verständnisfragen. Die Beameransicht vergrößert die Darstellung.

Modell: unipolarer idealer ADC, Intervallbreite Uref/2^n, Vergleichsspannung D_prüf*Intervallbreite, Gleichheit führt zum Behalten. Genau Uref wird gesättigt dem höchsten Code zugeordnet. Die Anzeige Uq nutzt die Intervallmitte (D+0,5)*Intervallbreite, passend zum vorausgehenden SOL-Blatt. Kein Anspruch auf gerätespezifische Übergangsschwellen oder reale Wandlungszeiten.

Fachliche Grundlage: Analog Devices, MT-021: ADC Architectures II: Successive Approximation ADCs, S. 1–2, https://www.analog.com/media/en/training-seminars/tutorials/mt-021.pdf (geprüft 04.10.2026). Aufgaben und Modellgrenzen sind didaktisch angepasste eigene Beispiele.
